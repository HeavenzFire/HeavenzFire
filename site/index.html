What this site does—and does not—claim

This page is a static public landing page. It does not mean the local Windows runtime, model gateway, mobile bridge, or agent fleet is running continuously. Live service status must come from timestamped health checks; missing or stale evidence means unknown, not online.

The project favors verifiable artifacts over superlatives: documented capabilities, repeatable tests, bounded permissions, and clear limitations.
